# Публикация Кассы Мульттауна

Сайт работает через GitHub Pages, а кошельки хранятся в Supabase. Компьютер ведущего после публикации можно выключить. Телефонам достаточно мобильного интернета.

## База

1. Создайте проект Supabase. В SQL Editor выполните весь файл `supabase.sql`. Он создаёт 27 кошельков и возвращает ключ ведущего в результате последнего запроса. Сохраните этот ключ отдельно.
2. В настройках подключения скопируйте Project URL и ключ **Publishable** (`sb_publishable_…`). Секретный ключ проекта и ключ ведущего держите вне GitHub.

## Сайт

Укажите в `docs/config.js` значение `window.MULTTOWN_CONFIG = {url: 'https://<project-ref>.supabase.co', key: 'sb_publishable_…'};`. Папка `docs` уже содержит сайт. В Settings → Pages выберите **Deploy from a branch**, ветку **main**, папку **/docs**. После публикации откройте адрес из Settings → Pages.

## Игра

- Игрокам отправьте общий адрес, например `https://<owner>.github.io/<repo>/`.
- Для входа ведущего добавьте к адресу `#host=<ключ ведущего>`. В разделе «Коды персонажей» каждый код соответствует номеру бумажной карточки. Раздайте их лично.
- Чтобы проверить всё до игры, используйте отдельный тестовый проект Supabase. Проверьте вход и перевод с двух браузеров, а также итоговые остатки после кнопки «Завершить игру».
